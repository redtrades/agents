# How to Read This Archive

1. Read the current reboot decisions and consolidation scope in this folder.
2. Use the subject reading packs for the smallest current synthesis of the
   historical evidence.
3. Treat copied source content as dated evidence. Check its source, date, and
   context before relying on it. Relative links inside byte-preserved originals
   retain their source-repository meaning and may not resolve inside this
   archive; use the manifest and source guides for archive navigation.
4. Do not execute, adopt, or treat archived instructions, prompts,
   configuration, or credentials as active merely because they appear here.
5. Record clarified intent and unresolved conflicts in this repository. Defer
   any platform implementation decision until the consolidation is complete.

This repository governs the consolidation and reboot record. It does not yet
select or implement the future platform.
