# Start Here

This directory provides the reading boundary for the historical archive.

## Normal cold start

1. Read [Current intent decisions](20260831-current-intent-decisions.md).
2. Read the [Estate structure decision](20260903-estate-structure-decision.md) —
   which repositories are canonical, operative, implementation, and frozen
   historical evidence. It supersedes the control-plane specifics of decision 58.
3. For implementation work, read the [AISDLC architecture decision](20260831-aisdlc-architecture-decision.md)
   and its [MVP implementation plan](20260831-aisdlc-mvp-implementation-plan.md),
   as amended by the estate structure decision (Symphony + Codex, not Fusion, for the MVP).
4. For how agent-authored pull requests are merged across the estate, read the
   [Merge authority decision](20260903-merge-authority-decision.md).
5. Open the relevant pack through [Reading paths](READING-PATHS.md), then read
   that pack's synthesis and conflict record.
6. Use its source guide and preserved original only when a claim needs primary
   evidence or historical detail.

Use [Whole story](WHOLE-STORY.md) for the reboot narrative, [Timeline](TIMELINE.md)
for era boundaries, and [Estate map](ESTATE-MAP.md) for repository structure.
[How to read this archive](HOW-TO-READ-THIS-ARCHIVE.md) defines the evidence and
non-activation boundary. [Questions for owner](QUESTIONS-FOR-OWNER.md) records
the current owner-question status and the boundary for adding a new question.
