# Agent Knowledge Archive

This repository is the working home for the historical consolidation and the
current first-principles reboot decisions that emerge from it. It preserves the
evidence needed to understand the full arc without inheriting the operating
rules or implementation assumptions of any source repository.

[`redtrades/agent-platform`](https://github.com/redtrades/agent-platform) is one
important source in that history. Its documentation, issues, source, and
reviewed history must be preserved and assessed, but they do not govern this
archive task merely because they were previously declared canonical.

Archived material may include superseded instructions, prompts, plans,
receipts, and other context. It is retained for provenance and comparison only.
Nothing copied from a source repository activates, governs runtime behavior, or
authorizes work merely by being present. Current reboot decisions are recorded
explicitly under `00-start-here/`.

For a normal cold start, read the [current reboot decisions](00-start-here/20260831-current-intent-decisions.md), then the relevant subject pack in the [reading paths](00-start-here/READING-PATHS.md). The separately approved current implementation direction is recorded in the [AISDLC architecture decision](00-start-here/20260831-aisdlc-architecture-decision.md) and [MVP implementation plan](00-start-here/20260831-aisdlc-mvp-implementation-plan.md). Consult a source guide or original only when the synthesis needs verification or historical detail.

The archive map is in [00-start-here](00-start-here/README.md). In particular,
the embedded `agent-platform` material is source evidence for this reboot, not a
governing instruction set.
