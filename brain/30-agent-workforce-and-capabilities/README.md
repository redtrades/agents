# Agent workforce and capabilities

## Default reading path

1. [Current historical synthesis](20260831-current-historical-synthesis.md)
2. [Decisions and conflicts](20260831-decisions-and-conflicts.md)
3. [Resolved owner questions](OPEN-QUESTIONS.md)

This pack reconstructs the agent workforce as reusable role blueprints plus scoped, portable capabilities. It does not select a runtime, install skills, or revive an earlier rule system.

## Boundaries

| Category | Meaning in this history | Not the same thing as |
| --- | --- | --- |
| Infrastructure | Runtime, orchestration, storage, identity, sandboxing, observability | A role or a skill |
| Capabilities | Skills, tools, plugins, MCP servers, models, prompts | The authority to act |
| Workflow artifacts | Versioned task cards, handoffs, reports, reviews, SOPs | Infrastructure |
| Knowledge | Sources, evidence, decisions, validated lessons | A live runtime memory |
| Policy | Authority, budgets, permissions, promotion rules | An agent configuration |

Read [Source guide](SOURCE-GUIDE.md) before using any selected original as more than historical evidence.
