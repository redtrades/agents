# Decompose the plan

1. Does this break into a 90-day objective, a weekly priority, and a daily action? If it can't break down that far, it's not a plan yet.
2. Is the vision in front of you daily, or only at planning time?
3. What tool or leverage point multiplies this, rather than just adding hours?
4. Does each layer trace back to the objective above it? Cut what doesn't.
